# Databricks Blueprints

End-to-end lakehouse builds on real public data, one every two weeks. Each sprint takes a real question, lands the raw data, cleans it through a bronze, silver, and gold medallion, and ends with something a person can actually use.

Built on Databricks Free Edition. Public data only.

| Sprint | Question | Data |
| :--- | :--- | :--- |
| [01](sprint-01-grid-demand/) | Does the AI data-center energy story show up in real U.S. grid demand? | EIA Open Data API |

## Setup

1. Copy `.env.example` to `.env` and add a free EIA API key from [eia.gov/opendata](https://www.eia.gov/opendata/register.php).
2. Each sprint folder has its own README with the run steps.
